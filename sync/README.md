# 사나이크럽 식단 자동동기화 (추가 서버 비용 0원)

- **ChatGPT**: 사용자 요청을 영양 계산 → 공개키 RSA 암호화 → GitHub 연동으로 커밋.
- **GitHub 공개 저장소**: 개인 식단은 저장하지 않고, 암호화된 이벤트 파일만 보관.
- **Android**: 비밀키는 Android Keystore에서 생성/보관. 실행/복귀 및 30분마다 공개 인박스를 확인. 복호화 성공 후 기존 'ironlog.v5.nutrition'에 병합. 저장 성공한 이벤트 ID만 처리 완료 표시.
- 설정/접속: 보급소 → ChatGPT 식단 자동 연동 → '연결키 복사' → ChatGPT에 붙여넣어 '사나이크럽 연결' 요청. ChatGPT가 기기 공개키를 'sync/devices/<device_id>.pem'에 등록.
- 이벤트 파일: 'sync/inbox/YYYY-MM/<uuid>.json'. 해독할 수 없는 JSON만 커밋. 이름과 파일 크기/커밋 시각 등의 메타데이터는 공개됨.
- 식사 기록은 기존 백업/수정/삭제 대상이며, 자동 연동은 로컬 기록을 서버 쪽에서 삭제하지 않는다. APK 삭제는 Keystore 비밀키 소실 위험이 있다.
- 현재 백그라운드 서비스는 없음. 앱을 다시 열면 연결된 이벤트를 자동 반영한다.
- 참고: 초기 암호화 이벤트는 12개월 분량까지 검사하며, 2개월 이전 월은 처음 한 번 스캔한다. 대량 이용에는 별도 저장소 및 정리 정책을 설계해야 한다.
- 별도 OpenAI API/유료 서버 불필요. GitHub 인증은 ChatGPT GitHub 연결에 의해 이루어지며, 휴대폰에는 GitHub 토큰을 저장하지 않는다.
